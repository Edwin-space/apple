# Safari 26.6.1, Sonoma·Sequoia에서 WebKit 취약점 22개 수정

**Safari 26 · 2026-08-18**

![Safari 26.6.1, Sonoma·Sequoia에서 WebKit 취약점 22개 수정](https://www.apple.com/newsroom/images/product/mac/standard/Apple-MacBook-Air-M5-hero_inline.jpg.large.jpg)

_이미지: Apple_

Safari 26.6.1이 macOS Sonoma와 Sequoia에서 다수의 WebKit 취약점을 수정했다.

## 핵심 변화

- 22개의 WebKit CVE가 수정됐다.
- 악성 웹 콘텐츠로 인한 메모리 손상 문제도 포함됐다.
- 구형 macOS를 유지하는 사용자도 Safari 업데이트가 필요하다.

## 왜 중요한가

OS 전체 업그레이드 없이도 브라우저 공격 표면을 크게 줄일 수 있는 중요한 보안 업데이트다.
