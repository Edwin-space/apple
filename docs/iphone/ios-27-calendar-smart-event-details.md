# iOS 27 Calendar, 자연어 일정 생성과 Busy/Free 추가

**iOS 27 · 2026-08-18**

Calendar가 Apple Intelligence 기반 자연어 일정 입력을 지원하고 iCloud 일정에 Busy/Free 상태를 추가하는 방향으로 확장됐다.

## 핵심 변화

- 자연어로 일정 내용을 입력하면 제목·시간·장소·초대 대상을 자동 구성한다.
- iCloud Calendar 일정별 Busy/Free 상태가 추가됐다.
- 일정 생성·편집 화면도 카드 중심으로 재설계됐다.

## 왜 중요한가

캘린더가 단순 입력 도구에서 AI가 구조화 작업을 대신하는 생산성 인터페이스로 바뀌는 변화다.
